# Отчёт по практической №1 — заполни своими решениями

## 1. Вариант и масштаб

| Поле | Значение |
|---|---|
| ФИО (как в VK Education) | [Твои ФИО] |
| Вариант (запрос) | Вариант 3 — Q18 |
| Масштаб `sfN` | sf1 |
| Почему выбрал такой масштаб | Объем данных sf1 (~250 МБ в сжатом виде) является оптимальным балансом: он позволяет локально в Docker тестировать сжатие и архитектурные решения без риска получить OutOfMemory, сохраняя при этом репрезентативность метрик. |

## 2. Поднятые сервисы — и почему именно они

| Сервис | Роль в стеке | Почему именно он (а не альтернатива) |
|---|---|---|
| MinIO | S3-совместимое объектное хранилище (сюда физически падают parquet-файлы) | Идеален для локальной эмуляции AWS S3. Разделяет compute и storage, позволяя хранить Parquet-файлы дешево и независимо от вычислительного движка. |
| PostgreSQL | БД, где Lakekeeper хранит метаданные каталога | Проверенная реляционная СУБД, обеспечивающая ACID-гарантии для транзакционного хранения указателей на версии таблиц (метаданные Iceberg). |
| Lakekeeper | Iceberg REST Catalog — каталог метаданных таблиц | Современная реализация по стандарту REST Catalog. Исключает конфликты библиотек (в отличие от Hive Metastore) и позволяет легко интегрировать любые движки. |
| Trino | SQL-движок: ходит в Lakekeeper за метаданными и читает/пишет данные в MinIO | Мощный MPP-движок, созданный специально для ad-hoc аналитики поверх Data Lake. Не требует тяжелой инициализации JVM на каждый запрос. |
| Apache Superset | BI-система: отчёт/дашборд поверх Gold | Легковесный open-source BI. Имеет нативную интеграцию с Trino (через SQLAlchemy), позволяя визуализировать витрины данных напрямую из Iceberg без копирования в сторонние БД. |

### Скрипты, которыми поднимал стек

```bash
# Использован docker-compose для управления инфраструктурой как кодом (IaC).
# Это надежнее ручного запуска отдельных контейнеров.
version: '3.8'
services:
  minio:
    image: minio/minio
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      - MINIO_ROOT_USER=admin
      - MINIO_ROOT_PASSWORD=password
      
  postgres:
    image: postgres:15
    environment:
      - POSTGRES_USER=lakekeeper
      - POSTGRES_PASSWORD=lakekeeper
      - POSTGRES_DB=lakekeeper
    ports:
      - "5432:5432"

  lakekeeper:
    image: lakekeeper/lakekeeper:latest
    environment:
      - DB_URL=postgres://lakekeeper:lakekeeper@postgres:5432/lakekeeper
      - S3_ENDPOINT=http://minio:9000
      - S3_ACCESS_KEY=admin
      - S3_SECRET_KEY=password
    ports:
      - "8181:8181"
    depends_on:
      - postgres
      - minio

  trino:
    image: trinodb/trino
    ports:
      - "8080:8080"
    volumes:
      - ./trino/catalog:/etc/trino/catalog
    depends_on:
      - lakekeeper
